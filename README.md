# 羽球拍配色模擬器

上傳羽球拍照片，模擬更換拍線顏色與握把布配色。
純前端、單一檔案，照片不會離開使用者的瀏覽器。

線上版：<https://badminton-racket-color-customizer.blackzxz77.workers.dev/>

## 檔案

- `index.html` — 全部的程式（HTML + CSS + JS，無外部相依）
- `DEPLOY.md` — 部署說明

## 開發

沒有建置流程。用瀏覽器直接開 `index.html` 就是開發環境，
改完存檔重新整理即可。

## 功能

- 拍線：橢圓定位、主線／橫線分色、線徑與線數、交織與投影
- 握把布：螺旋纏繞、六角柄面光影、材質（PU／打孔／毛巾）、雙色交替
- 設定與位置比例會記在瀏覽器的 localStorage，可一鍵存成個人預設
- 復原／重做
- 手機雙指縮放、桌機滾輪縮放
